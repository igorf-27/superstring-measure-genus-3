# RNS superstring measure for genus 3
## Supplementary material

The file `formula-for-xi3.txt` contains a formula for the modular form $\Xi^{(3)}$ appearing in the paper [RNS superstring measure for genus 3](https://arxiv.org/abs/2505.02950). Namely, it is the formula (1.5b) with the numerical coefficients (1.6) substituted and all ingredients expanded. The expression that results is a rational function of theta constants and theta gradients, see remark 4 at the end of section 1.7.

The following notation is used in the file. If `i`, `j`, `k` are digits, then

- `tij` is the theta constant with characteristic `ij`,
- `tijk` is the partial derivative of the theta function with characteristic `ij` with respect to $z_k$ at $z=0$.

The notation for theta functions and characteristics is explained in appendix A of the paper.
